# Shared laundry room

## AppWash

- Service: `web.appwash.com`; use the existing signed-in personal browser session.
- Price: 2.80 € per machine start for both washing and drying. The price displayed in the service is per start, rather than per selected program duration.
- The selected site currently lists five washing machines and two dryers. Availability changes live; do not preserve a snapshot as current truth.
- Confirmed photographed washer: AppWash machine **50937**, named **House 3D Waschmaschine**. Its display shows selectable programs and a remaining-time display. The visible program was `Buntwäsche`.
- Likely washer family: Schulthess proLine Gen2 W65/W80/W100. The front and 4.3-inch color display match this family. Treat W65 (7 kg) as the temporary planning assumption, not as a confirmed model. The possible cotton capacities are 7/9/11 kg; confirm the type plate before relying on an exact capacity.
- Confirmed photographed dryer: Miele Professional PDR 908 HP [EL], an 8 kg heat-pump dryer. Typical `Schranktrocken` timing is around 67 minutes for mixed fabrics and 77 minutes for cotton. It has selectable programs; the local AppWash pricing and enabled program list determine what can be chosen.

## Using the room

1. Open the existing AppWash session and choose `Waschen` or `Trocknen`.
2. Check that the desired machine is shown as available. The displayed machine number should match the physical sticker.
3. Load only the planned compatible family. The drum should be full enough to make the fixed price worthwhile, while the textiles still move freely; do not force the door shut.
4. Choose the planned program and follow the product labels. Do not change a paid booking or begin a cycle without the user's explicit request.
5. For drying, re-check the labels. The mattress cover and the recorded kitchen towels must air-dry.
